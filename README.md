# mle-razrabotka-v-ide

## Описание проекта
В рамках данного проекта реализован класс `DataFrameReporter`, который решает проблему быстрого и информативного первичного анализа данных (EDA). 
Вместо того чтобы каждый раз вручную писать код для вывода размеров датафрейма, подсчета дубликатов и пропусков, вы можете использовать этот класс. Он выводит сводный отчет в удобном формате, который можно гибко настраивать (например, задавать точность вывода дробных чисел или включать полную статистику).
